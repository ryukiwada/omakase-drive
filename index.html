試作・出発前のコース確認専用
ルート全体の道幅保証、車線案内・GPSナビは未実装。安全な走行ルートを保証しません。運転中は操作しないでください。

出発・帰着：和歌山駅付近（仮の地点）

交通状況を考慮しない概算です。希望時間どおりになる保証はありません。

地形や道路網の制約で、同じ道を通る場合があります。判定は経路形状からの概算です。

「なるべく利用しない」はValhallaで高速道路の優先度を最低にして計算します。高速道路や有料道路を完全に除外する設定ではありません。無料の公開デモを使うため、検索できない場合があります。

「避ける」設定ではValhallaの道路種別ごとの経路コストを調整します。車線数・実際の道幅は判定できません。片側1車線以上を保証する機能ではなく、狭い道が含まれる場合があります。

照合できた地点の道路分類のみを参考にします。未照合・分類不明は安全とみなしません。時間・周回の条件は維持します。

地点を変更するか、そのまま生成できます。
📂 地域別の道路データ（v0.9.3）
Overture Mapsなどの道路分類を含むGeoJSONを読み込み、ブラウザ内に保存します。APIへの問い合わせなしで検査できます。道路データは初回のみ読み込みが必要です。保存済みなら自動的に復元します。
別途 GitHub Actions で wakayama_roads.geojson を生成して公開する必要があります。未配置の場合は読み込めません。対象は和歌山市周辺の試験範囲のみ。道路分類は参考情報で、車線数・幅員は未確認です。
道路データを確認中…
GeoJSONのLineString/MultiLineStringに対応。道路種別・車線数・幅員が不明な場合は未確認として扱います。地点の近傍照合なので安全性の保証ではありません。iPhoneのブラウザ保存領域が消えるとデータも失われます。
🛣️ 従来の通信診断・API検査（v0.8.4）
「APIの通信診断」はルート生成不要で、APIの状態確認と和歌山市内1地点の軽い検索を分けて試します。コース検査は従来どおり最大8地点です。道路幅を保証する機能ではありません。
